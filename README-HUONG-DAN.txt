HƯỚNG DẪN CẬP NHẬT WEBSITE 20/10

1. Giải nén ZIP này.
2. Mở thư mục vừa giải nén. Bạn sẽ thấy index.html, styles.css, script.js,
   magic-disc.html, autoplay-music.js, thư mục images/ và thư mục music/.
3. Tải TẤT CẢ các file và thư mục này lên cùng một thư mục gốc của repository
   GitHub Pages. Không chỉ tải riêng index.html và magic-disc.html.
4. Giữ nguyên tên file và chữ hoa/chữ thường; không đổi vị trí thư mục images/
   hoặc music/.
5. Commit/push rồi đợi GitHub Pages cập nhật. Mở lại website và tải mới trang.

Các đường dẫn asset trong website là đường dẫn tương đối, ví dụ:
images/bouquet-a10.png
images/garden-flowers-a12.png
music/co-chac-yeu-la-day.mp3

Nếu repository của bạn xuất bản từ thư mục /docs hoặc một thư mục con khác,
hãy đặt toàn bộ nội dung ZIP vào đúng thư mục nguồn đang được cấu hình cho Pages.
